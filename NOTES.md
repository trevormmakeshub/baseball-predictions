This repo predicts an MLB moneyline, a run line, and a game total for the same game, plus a Pick 6 player-prop card.

Completed games were pulled from the MLB Stats API on 2026-11-07. data_files/processed/completed_games.parquet has 15776 finals from 2020-07-23 through 2026-10-28, including 2469 games in 2026. The schedule was checked through 2026-11-07. No sportsbook was called. This does not price a bet.
